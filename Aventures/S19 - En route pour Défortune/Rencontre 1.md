# Installation

Les joueurs partent de Suzail en direction de [[Défortune]]. Sur cette première journée, leur but est d'atteindre le village de Waymoute. Ce village doit obligatoirement être traversé pour ensuite partir pour Défortune et il se situe à une journée à cheval de Suzail.

Pendant cette rencontre, les PJ peut être amenés à avoir une ou deux rencontres animant la travers comme listés dans le tableau suivant : 

| Lancer D10 | Résultat                                                                                                            |
| :--------- | ------------------------------------------------------------------------------------------------------------------- |
| 1-2        | Des voyageurs en détresse se retrouvent coincés, une des roues de leur charette complètement cassée                 |
| 3-4        | Des satyres accompagnés d'un Ours-Hibou bloquent les joueurs, leur demandant de payer une taxe pour pouvoir passer. |
| 5-6        | Des brigands plus préparés attendent les PJ pour les éliminer                                                       |
| 7-8        | Un marchand itinérant colporte des rumeurs sur la forêt royale (Tertre-elfe entre autre)                            |
| 9-10       | Des fées usent de magie pour charmer les PJ let les perdre dans la forêt                                            |
