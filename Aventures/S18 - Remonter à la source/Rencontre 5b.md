# Créatures

Cette rencontre inclut les créatures suivantes :
- Gardes dragons pourpres
- Sergent
- Mage de Guerre
- Erzoured, Baron Ormefort

Cette rencontre est spéciale. En ffet celle-ci commence avec les créatures suivantes : 

- 1 Erzoured, Baron Ormefort (E)
- 4 Gardes dragons pourpres
- 1 Sergent

À chaque tour, de nouvelles forces arrivent pour acculer les PJ et s'obliger à se rendre. Pour l'ajout de créatures, Vous devez lancer un D6 et suivre le tableau de résultat suivant : 

| Lancer | Résultat                   |
| ------ | -------------------------- |
| 1-2    | 1 Mage de guerre, 2 gardes |
| 3-4    | 3 gardes                   |
| 5-6    | 2 mages de guerre          |
