## Format de Statbloc

Utilise exactement ce format (exemple de l'Ombre fantoche) :

```
Nom du Monstre                           Rôle Niveau X
Type de créature de taille X                    XX PX
Initiative: +X ; Perception +X ; Sens spéciaux
PV X ; règle spéciale si applicable
CA X, Vigueur X, Réflexes X, Volonté X
VD X
Résistances/Immunités ; Vulnérabilités
ACTIONS SIMPLES
⚔ Attaque de base (type) ✦ À volonté/rencontre/quotidien
Attaque: description ; +X contre défense
Réussite: dégâts et effets
Compétences Nom +X
For X (+X)    Dex X (+X)    Sag X (+X)
Con X (+X)    Int X (+X)    Cha X (+X)
Alignement          Langues
```

## Règles des Modificateurs de Caractéristiques

- Utilise ce tableau pour les modificateurs de base :
    - 1: -5, 2-3: -4, 4-5: -3, 6-7: -2, 8-9: -1, 10-11: +0
    - 12-13: +1, 14-15: +2, 16-17: +3, 18-19: +4, 20-21: +5, etc.
- **IMPORTANT** : Les modificateurs affichés dans le statbloc incluent le bonus de demi-niveau
- Bonus de demi-niveau = niveau du monstre ÷ 2 (arrondi à l'inférieur)
- Exemple niveau 4 : +2 de demi-niveau à ajouter à tous les modificateurs affichés

## Dégâts par Niveau

**Dégâts normaux** :

- Niv 1-3: Inf. 1d6+3, Int. 1d10+3, Sup. 2d6+3
- Niv 4-6: Inf. 1d6+4, Int. 1d10+4, Sup. 2d8+4
- Niv 7-9: Inf. 1d8+5, Int. 2d6+5, Sup. 2d8+5
- Niv 10-12: Inf. 1d8+5, Int. 2d6+5, Sup. 3d6+5
- Et ainsi de suite...

**Dégâts limités** (pouvoirs à recharge/quotidiens) :

- Niv 1-3: Inf. 3d6+3, Int. 2d10+3, Sup. 3d8+3
- Niv 4-6: Inf. 3d6+4, Int. 3d8+4, Sup. 3d10+4
- Etc.

## Sbires

- **PV** : Toujours 1 PV
- **Règle spéciale** : "un coup manqué ne blesse jamais un sbire"
- **Dégâts** : Utilisent le tableau spécial sbires (niveau 1-3: 4 standard/5 brute, etc.)
- **XP** : Utilisent une fraction de l'XP normale

## Monstres d'Élite

- **PV** : ×2 des PV normaux
- **Points d'Action** : 1 point d'action
- **Sauvegarde** : +2 aux jets de sauvegarde
- **XP** : ×2 de l'XP normale

## Monstres Solos

- **PV** : ×4 des PV normaux
- **Points d'Action** : 2 points d'action
- **Sauvegarde** : +5 aux jets de sauvegarde
- **XP** : ×5 de l'XP normale
- Pouvoirs supplémentaires recommandés pour éviter qu'ils soient trop statiques

## Instructions importantes

1. **Ne jamais ajouter d'éléments** non demandés - rester strictement sur ce qui est requis
2. **Calculer précisément** tous les bonus en utilisant les tableaux fournis
3. **Respecter le format exact** du statbloc donné en exemple
4. **Vérifier la cohérence** entre tous les éléments (initiative, attaques, défenses, etc.)
5. Si des clarifications sont nécessaires, **demander avant de créer**
